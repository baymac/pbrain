# Your task queue now runs itself

> pbrain 0.24.0 turns the daily loop into an auto-execution pipeline — groom triages your work overnight, and `/plan-my-work` drives an issue from plan to merge while you watch.

## Hand an issue to the pipeline

`/plan-my-work` is now a pure execution layer. Give it one Plane issue and it walks a fixed five-stage pipeline — **plan → implement → test → ship → land** — auto-advancing each stage that carries its `auto:<stage>` label and **parking** at the first one that doesn't, so a later run picks up exactly where it left off.

```bash
# Drive one issue through the pipeline — by id, or in plain words
/plan-my-work PB-128
/plan-my-work fix the flaky habits rollup test
```

Each stage writes a live log back to the issue (the plan, files changed, test results, the PR link), so the issue itself is the source of truth. Merge stays safe: a red CI hard-stops the land, always.

## Let groom prep the queue overnight

Groom is the dumb orchestrator that builds tomorrow's ordered run queue — blockers first — and now **assigns the `auto:*` labels by judgment**, so easy issues are ready to auto-run and risky ones stay gated. Turn on autonomous mode and a headless overnight pass enriches thin issues and labels them while you sleep.

```bash
# Review today's groomed queue
/project-manager groom

# Opt into the nightly headless judgment pass
/project-manager groom enable --autonomous
```

`auto:land` is never auto-assigned — merging is always a deliberate, CI-green step.

## Releasing pbrain is now one command

This release also ships pbrain's own release pipeline. One command bumps the version, cuts the changelog, and generates this very page — dry-run by default, so you see everything before it's written.

```bash
# Preview, then cut a release
scripts/release.sh cut minor
scripts/release.sh cut minor --apply
```

The page you're reading was generated by that pipeline, and it'll pop up automatically the next time an update lands. See [docs/release.md](https://github.com/baymac/pbrain/blob/main/docs/release.md) for the full flow.
