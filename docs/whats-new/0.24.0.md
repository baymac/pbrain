# Your task queue now runs itself

> pbrain 0.24.0 turns the daily loop into an auto-execution pipeline, a smarter overnight groom, and a real project + infra backbone — Plane on a VPS, vault backups, and a one-command release.

## The new mental model: a 5-stage pipeline

`/plan-my-work` is now a pure execution layer. Hand it one Plane issue and it walks five stages, auto-advancing each one that carries its `auto:<stage>` label and **parking** at the first one that doesn't — so a later run resumes exactly where it stopped.

```flow
plan -> implement -> test -> ship -> land
```

```bash
# Drive one issue — by id, or in plain words
/plan-my-work PB-128
/plan-my-work fix the flaky habits rollup test
```

Each stage logs back to the issue (plan, files changed, test results, PR link). Merge stays safe: a red CI hard-stops `land`, and `auto:land` is **never** auto-assigned.

## Groom preps tomorrow's queue while you sleep

Groom is the dumb orchestrator that builds the ordered run queue (blockers first) and now labels issues by judgment. Turn on autonomous mode for a headless overnight pass.

```bash
/project-manager groom                      # review today's queue
/project-manager groom enable --autonomous  # nightly headless judgment pass
```

| Change | What it does |
|---|---|
| **Judgment labels** | Groom assigns `auto:plan/implement/test/ship` by real complexity — never `auto:land`. |
| **Quality gate** | Catches half-baked issues (`x`, `wip`, "fix the thing"), enriches them, marks them `auto:groomed`. |
| **Autonomous nightly** | `enable --autonomous` runs a headless Claude triage pass overnight; triage-only, bounded. |
| **Weekly-goal scope** | Defaults to this week's weekly-goal projects; clickable issue links by shortcut. |
| **FDA vault writes** | Nightly groom now writes grooming data into the iCloud vault via a signed helper. |

## Project management got a real backbone

| Feature | Command | Use it for |
|---|---|---|
| **Spec / approval gate** | `/project-manager spec <id>` | Socratic walk that drafts + approves a plan so the pipeline skips live planning |
| **Task execution + workdir** | `/plan-my-work task execute` | Per-project working location; isolated worktree off fresh `origin/main` |
| **Host Plane on a VPS** | `/project-manager host` | Move Plane off localhost — deploy, domain, VPN, import, wire |
| **Daily Plane backups** | `/project-manager backup` | pg_dump + uploads → local / external / VPS, with retention + restore |
| **GitHub setup** | `/init-plane github` | Wire GitHub integration into your Plane instance |
| **Label color repair** | `/project-manager labels --seed` | Self-repairs colors on existing convention/gate labels |
| **Correct issue links** | — | Links now use your browser host, not the `127.0.0.1` loopback |

## Your data, backed up and private

```bash
/vault-backup enable     # nightly off-iCloud vault snapshots
/vault-backup now        # snapshot on demand; restore is non-destructive
```

- **Off-iCloud vault backup** — `tar.gz` of your vault → local / external / VPS, retention, stale-backup alerts, restore-into-a-dir (never over the live vault).
- **Self-improve pass (PB-47)** — at `/end-of-day`, pbrain mines the day's sessions for corrections you made and proposes them, one at a time, before writing anything.
- **Security** — your Plane access token is never echoed to the terminal or logs.

## Releasing pbrain is now one command

This release ships pbrain's own release pipeline — it generated this very page.

```bash
scripts/release.sh cut minor          # preview (dry-run)
scripts/release.sh cut minor --apply  # bump + changelog + this guide
```

Dry-run by default, idempotent, and the page pops up automatically the next time an update lands. See [docs/release.md](https://github.com/baymac/pbrain/blob/main/docs/release.md).
