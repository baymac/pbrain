# Your task queue now runs itself

> pbrain 0.24.0 turns the daily loop into an auto-execution pipeline, a smarter overnight groom, and a real project + infra backbone — Plane on a VPS, vault backups, and tighter privacy.

## The new mental model: a 5-stage pipeline

`/plan-my-work` is now a pure execution layer. Hand it one Plane issue and it walks five stages, auto-advancing each one that carries its `auto:<stage>` label and **parking** at the first one that doesn't — so a later run resumes exactly where it stopped.

```flow
plan -> implement -> test -> ship -> land
```

```bash
# Drive one issue — by id, or in plain words
/plan-my-work PB-128
/plan-my-work fix the flaky habits rollup test
```

Each stage logs back to the issue (plan, files changed, test results, PR link). Merge stays safe: a red CI hard-stops `land`, and `auto:land` is **never** auto-assigned.

## Groom preps tomorrow's queue while you sleep

Groom builds your ordered run queue (blockers first) and now labels issues by judgment. Turn on autonomous mode for a headless overnight pass, then wake to a ready queue.

```bash
/project-manager groom                      # review today's queue
/project-manager groom enable --autonomous  # nightly headless judgment pass
```

| Change | What it means for you |
|---|---|
| **Judgment labels** | Groom decides which stages auto-run per issue — never `auto:land`, so merges stay yours. |
| **Quality gate** | Half-baked issues (`x`, `wip`, "fix the thing") get enriched before they reach the queue. |
| **Autonomous nightly** | `enable --autonomous` triages overnight; you review a finished queue in the morning. |
| **Weekly-goal scope** | Defaults to this week's goal projects, with clickable issue links. |

## Plan your work with a spec gate

```bash
/project-manager spec PB-42   # Socratic walk → drafts + approves a plan
/plan-my-work PB-42           # approved issues skip the live planning step
```

Approve a plan once and the pipeline runs it without re-asking — less hand-holding, fewer surprises mid-build.

## Run Plane wherever you need it

| Feature | Command | Use it for |
|---|---|---|
| **Host Plane on a VPS** | `/project-manager host` | Move Plane off localhost — deploy, domain, VPN, or import an existing instance |
| **GitHub setup** | `/init-plane github` | Wire GitHub integration into your Plane instance |
| **Daily Plane backups** | `/project-manager backup` | Snapshots → local / external / VPS, with retention + restore |
| **Tidier labels & links** | `/project-manager labels --seed` | Repairs label colors; issue links now open your real host, not `127.0.0.1` |

## Back up your vault, keep it private

```bash
/vault-backup enable   # nightly off-iCloud vault snapshots
/vault-backup now      # snapshot on demand; restore never overwrites the live vault
```

- **Off-iCloud vault backup** — a full snapshot of your vault to local / external / VPS, with retention and stale-backup alerts.
- **pbrain learns from your corrections** — at `/end-of-day` it reviews the day and proposes improvements it noticed, one at a time, before changing anything.
- **Your Plane token is never shown** — it stays out of the terminal and logs.
